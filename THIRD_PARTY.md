# Third-party resources

The MIT license covers original WalkEdit code. External resources retain their applicable terms.

| Resource | Use | Terms and source |
| --- | --- | --- |
| KTH Actions | Video source for the SMPL-X demo | Publicly available for non-commercial use. Credit Christian Schuldt, Ivan Laptev, and Barbara Caputo, “Recognizing Human Actions: A Local SVM Approach,” ICPR 2004. [Source](https://www.csc.kth.se/cvap/actions/) |
| ACCAD Open Motion Project | BVH example and skeleton demo | CC BY 3.0. Credit ACCAD / The Ohio State University. Demonstrations crop and retime Figure Quick Walk. [Source](https://accad.osu.edu/research/motion-lab/mocap-system-and-data) |
| SMPL-X | Parametric body and mesh | Separate model terms. Obtain the body model through the official provider. [License](https://smpl-x.is.tue.mpg.de/modellicense.html) |
| MediaPipe | Landmark estimation | Upstream code and model terms apply. [Project](https://github.com/google-ai-edge/mediapipe) |
| GVHMR | Optional external recovery backend | Its code, dependencies, and weights retain upstream terms. [Project](https://github.com/zju3dv/GVHMR) |

The hero image, SMPL-X GIF, and SMPL-X MP4 show the reconstructed KTH demonstration. Segment comparison media show modified ACCAD motion. These demonstration outputs retain applicable source and model conditions.

Raw datasets, body models, pretrained weights, and generated parameter tensors are stored outside the tracked source tree.
